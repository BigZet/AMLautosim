# API routers

По одному небольшому HTTP-модулю на функциональную область:

- `auth.py` — регистрация, вход, logout и проверка сессии;
- `rounds.py` — активный раунд и карточки;
- `scenarios.py` — GET, PUT и submit сценария;
- `leaderboard.py` — результат и публичный рейтинг;
- `admin.py` — административные команды.

Router проверяет запрос, вызывает `services/` и возвращает DTO из `schemas/`.
