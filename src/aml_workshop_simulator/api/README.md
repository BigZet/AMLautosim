# API

FastAPI application и HTTP-слой.

Примеры будущих файлов:

- `main.py` — создание FastAPI app и подключение routers;
- `deps.py` — текущая сессия, RBAC и зависимости сервисов;
- `middleware.py` — request ID, error envelope и безопасное логирование;
- `health.py` — `/health/live` и `/health/ready`.

SQL-запросы и игровые формулы сюда не помещаются.
