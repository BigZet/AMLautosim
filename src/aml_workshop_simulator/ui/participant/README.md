# Participant UI

Интерфейс участника мастер-класса:

- `app.py` — Streamlit entry point и навигация;
- `login.py` — регистрация и вход;
- `builder.py` — конструктор сценария и динамические формы;
- `result.py` — объяснение результата;
- `leaderboard.py` — публичный рейтинг.

Локальный preview не является каноническим результатом и не заменяет ответ API.
