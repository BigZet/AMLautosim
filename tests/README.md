# Test suites

- `unit/` — правила, скоринг, DTO и небольшие изолированные тесты;
- `integration/` — FastAPI, Streamlit client, PostgreSQL и Alembic;
- `e2e/` — полный сценарий мероприятия через Docker Compose.

Нагрузочные, security и contract-проверки оформляются обычными тестовыми файлами в
подходящем уровне. Отдельный каталог заводится только тогда, когда таких файлов станет
действительно много.
