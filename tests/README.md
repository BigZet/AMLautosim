# Тесты FastAPI

Набор проверяет текущий API и игровой движок. Старые тесты удалённых контрактов,
миграций и Streamlit заменены; проверки нового Streamlit появятся при его обновлении.

## Запуск

Нужны Python 3.13, зависимости `requirements-dev.txt` и PostgreSQL 16.
Пользователь PostgreSQL должен иметь право `CREATEDB`.

```bash
python -m pip install -r requirements-dev.txt
export TEST_ADMIN_DATABASE_URL=postgresql://aml:aml@localhost:5432/postgres
python -m pytest -q
```

Каждый запуск создаёт БД `aml_test_<uuid>`, применяет `alembic upgrade head`,
а при завершении удаляет именно эту БД. Рабочий `DATABASE_URL` игнорируется.
Между HTTP-тестами очищается только временная БД и выполняется seed.
При принудительном завершении процесса временная БД может остаться на сервере.
Не запускайте набор внутри процесса работающего приложения: conftest задаёт его
тестовые настройки до импорта FastAPI.

Только игровой движок, без запущенной БД:

```bash
python -m pytest -q tests/unit
```

## Состав

- `api/test_auth.py`: сессии, роли, изоляция данных, истечение срока, блокировка входа.
- `api/test_scenarios.py`: автосохранение, восстановление, preview, ревизии,
  UUID повторной команды, атомарная финальная отправка и ошибки карточек.
- `api/test_rounds.py`: отсутствие игры, конфигурация, запуск, перезапуск и удаление
  неотправленных цепочек при закрытии приёма.
- `api/test_scoring.py`: откат записанных оценок при сбое, повтор расчёта,
  совпадающие места, блокировка участника и единые представления результата.
- `api/test_concurrency.py`: реальные конкурентные HTTP-запросы и блокировки PostgreSQL;
  чтение состояния одним SQL-запросом без ожидания завершения скоринга.
- `api/test_contract.py`: OpenAPI, ошибки, readiness, текущая миграция и идемпотентный seed.
- `unit/test_game_engine.py`: денежный расчёт, цель, ресурсы, квоты, ограничения цепочки.

HTTP проходит через ASGI TestClient с lifespan приложения и реальными сервисами/БД.
Подменяется только точка расчёта для контролируемого сбоя или задержки; SQL и
транзакции остаются настоящими. Это не нагрузочный тест и не проверка браузерного UI.
