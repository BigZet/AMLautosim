# Аудиторские тесты (добавлены ревизией 2026-08-30)

Набор написан во время независимой ревизии проекта и **не изменяет** существующие
тесты. Каждый тест фиксирует наблюдаемое поведение текущего кода и служит
воспроизведением для замечаний из `PROJECT_AUDIT.md`.

Тесты помечены так, что «падение» означает «дефект исправлен»: там, где тест
закрепляет дефектное поведение, это явно написано в docstring.

```bash
python -m pytest tests/audit -q
```

Требования те же, что и у остальных наборов: PostgreSQL 16 и переменные
`TEST_ADMIN_DATABASE_URL` / `TEST_DATABASE_URL` (см. `tests/README.md`).
