# Unit tests

Быстрые изолированные тесты без PostgreSQL и HTTP:

- `test_resources.py` — расчет игровых ресурсов;
- `test_scoring.py` — риск и итоговый балл;
- `test_scenario_rules.py` — бизнес-валидация;
- `test_schemas.py` — строгие Pydantic DTO;
- `test_leaderboard.py` — ranking и tie-breakers.
