# Дополнительные проверочные скрипты

Это снимки скриптов аудита, а не изменения продукта. Запускались из корня worktree, обычным Python (без -O, кроме специального негативного теста выпуска). Команды и результаты: ../*.json и ../*.log. Скрипты используют изолированный Compose project и локальные settings/storage-state, которые намеренно не опубликованы. Для повторения требуется создать собственные секреты, тестовые учётки и сессии. Не направлять эти сценарии на рабочую БД.

model_probe.py дополнительно использовал локальные контрольные цепочки scoring-ui-scenarios.json; этот локальный набор не является общедоступной fixture. Полностью репозиторный контроль — tests/fixtures/retired_limits_baseline.json и тесты из scoring-tests.json. fault_server.py — временная обёртка тестового процесса, в обычный запуск не включена.
