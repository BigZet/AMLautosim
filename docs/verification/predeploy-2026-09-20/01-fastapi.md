## Замечания

### DEP-01 · P1 · Продукт/поставка: контейнер запускает прежний пакет

Места: docker-compose.yml (AML_PROBABILITY_MODEL_PATH), deploy/Dockerfile (COPY пакетов), .dockerignore (исключения resources). Пакет `aml-game-organizer-settings-v1` отсутствует в образе. В контейнере идентификатор модели начинается `eb686e2f…`; сохранение новой цели возвращает **409 model_contract_mismatch**, хотя UI предлагает редактирование. Воспроизведение: [container-probe.log](container-probe.log). Требуется согласовать содержимое образа, выбор пакета и текущий релиз, затем повторить полный контейнерный сценарий.

### API-01 · P1 для v8 · Продукт: legacy-скоринг не принимает собственный контракт

Два теста гонок падают с HTTP 500. [Диагностика](fastapi-error-cause.log): `ModelScorer.check_config` принимает конфигурацию, но `AMLModelAdapter.predict` повторно проверяет исходный финансовый контракт и выдаёт `This model does not support the round financial contract`. Проверка внешнего адаптера учитывает удалённые лимиты, внутренняя — нет. Места: services/model_scoring.py и services/aml_risk_model.py. Поддержка v8 остаётся в маршрутах, seed и старых сохранённых раундах; проблему нельзя списать только на тест. Новые v10-настройки и скоринг прошли отдельный тест.

### TEST-01 · P2 · Устаревший тест

`test_unsupported_financial_configuration_is_rejected_atomically` ожидает 409 при изменении начальной энергии. Теперь организатору это разрешено и API возвращает 200. Тест нужно обновить по согласованному контракту, не возвращать старый запрет.

## Ограничения проверки

Конкурентные проверки на v8 не дают положительного заключения из-за указанного сбоя. Домен, TLS, reverse proxy, лимиты внешнего трафика и инфраструктура целевого сервера не заданы и не проверены. Рабочие пароли/токены в доказательства не включены.
