## Итог

**Обнаруженные блокеры и дефекты исправлены; повторные проверки пройдены.** Docker запускает актуальный пакет, настройки организатора сохраняются, legacy v8 рассчитывается, упаковка проверяет входы и при `python -O`, закрытие диалога не вызывает исключения.

### Модель и Linux

[Контроль модели](linux-model-final.log): **25 признаковых векторов и вероятностей совпадают точно**; диапазон 15 цепочек 0,000973319–0,999897030. Максимальная невязка SHAP 3,197e−14. Повреждённая копия артефакта отклонена. [Контрольные цепочки](control-chains.json) не содержат учётных данных.

Стенд: Linux x86_64 под Docker Desktop/WSL2, Python 3.13, 12 доступных логических CPU; отдельный Compose project `aml-predeploy-fixes-20260920`, PostgreSQL 16, порты 55490/18010/18090. Измерен последовательный инференс 15 цепочек с SHAP: **2,558 с**, медиана **166,39 мс**, максимум **215,05 мс**. Это не HTTP-нагрузочная проверка и не SLA внешнего сервера.

[Проверка финального образа](runtime-integrity.json): 134 включённых исходных файла совпадают с рабочим деревом; пакет и его идентичность совпадают с исходным аудитом. Исключённый Dockerfile/.dockerignore старый обучающий модуль отдельно перечислен. Изменение контролируемых исходников актуального пакета не потребовалось, поэтому переупаковка рабочего модельного релиза не выполнялась. Обучающие наборы, веса, признаки, калибровка, пороги и архивные результаты не менялись.

Первый Linux-пробник не смог изменить read-only файл в временной копии; права исправлены только у этой копии, runtime остался read-only. Первый скрипт сравнения backup содержал ошибку SQL; исправленный повтор проверил данные. Эти промежуточные ошибки отражены в логах и не являются дефектами продукта.
