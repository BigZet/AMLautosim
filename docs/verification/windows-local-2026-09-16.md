# Проверка локального запуска Windows — 2026-09-16

## Окружение

- Python 3.13.15, отдельное окружение `.venv`, 82 пакета из `requirements-dev.txt` с транзитивными зависимостями.
- PostgreSQL 16.15: официальный [архив EDB](https://www.enterprisedb.com/download-postgresql-binaries), локально в `.local-run/postgresql/pgsql`.
- PostgreSQL слушает `127.0.0.1:55439`, API — `127.0.0.1:8000`, NiceGUI — `127.0.0.1:8080`.
- Создан локальный `.env` со случайными паролями и секретом. Секреты и БД исключены из Git.
- Docker не установлен; контейнерная сборка в этой проверке не выполнялась.

## Исправления

- Для `uvloop` добавлен маркер исключения Windows в обоих списках зависимостей. До исправления установка завершалась ошибкой `uvloop does not support Windows`.
- В `.gitattributes` закреплены LF для четырёх исходников, проверяемых манифестом модели, JSON ресурсов и конфигурации модели. CRLF после Windows checkout нарушал проверку SHA-256 и блокировал скоринг и seed. Восстановленный LF совпадает с исходными контрольными суммами; манифесты и содержимое модели не менялись.
- Для запуска используется `PYTHONUTF8=1`: системная кодировка cp1252 приводила к ошибкам чтения и вывода русского текста.
- Проверка символических ссылок отделена от проверки воспроизводимости архива. Только тест ссылок пропускается при WinError 1314; остальные ошибки не скрываются.
- В README добавлены команды PowerShell.

Всего 467 успешных тестов, один пропуск: Windows не разрешает создавать символические ссылки текущему процессу. Два предупреждения об устаревающих API Starlette/AnyIO не влияли на результат.

API и нагрузочные тесты использовали собственную временную PostgreSQL-базу. Нагрузочный тест проверяет 50 контроллеров, а не 50 браузеров. Полный игровой путь покрыт автоматическими API/NiceGUI-тестами; вручную в Chrome проверена страница входа. Полная офлайн-проверка 4413 прогнозов отдельно не запускалась.
