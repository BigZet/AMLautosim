## Что подготовлено

- Упаковщик включает актуальный `aml-game-organizer-settings-v1`, оболочку `aml-game-attribute-context-unlimited-v1` и прежние поддерживаемые пакеты.
- Архив собирается временно, проверяются состав и SHA256, затем публикуется атомарной hard-link операцией без перезаписи. Неподходящие файловые системы дадут явный отказ, а не неатомарную публикацию.
- Проверяются отсутствие приватных файлов в разрешённых каталогах и symlink; локальные БД, секреты и backup не входят. Тесты подмены checksum, отказа публикации и повторного выпуска добавлены.
- Включён `deploy/compose.image.yml` для запуска загруженного образа с `--no-build`; актуализированы инструкции v10, настройки организатора, первый запуск, обновление и откат.
- Последние UI-исправления включены в образ, код не подмонтирован. Из host-каталогов API читает только конфигурацию из распакованного архива; UI использует отдельный том сессий.

## Общий набор тестов и ограничения допуска

Команда `pytest tests/unit tests/api -q`: **973 passed, 77 failed, 11 errors, 1 skipped**, 660,77 с. Полный [лог](tests.log), [команда](tests.json). Сессионные идентификаторы обезличены. Это более широкий прогон, чем прошлый аудит.

Разделение обнаруженного:

1. Исследовательские генераторы, casebook/dataset, демонстрационные training fixtures: рассогласование фиксированного финансового контракта после удаления лимитов, ошибки построения matched pairs и связанные зависимые проверки. Эти пути не используются текущим закреплённым классификатором при игре. Архивы/обучающие наборы и их проверки целостности не переписывались и не отключались. **Открыто**, требуется отдельное согласование совместимости исследовательского контура.
2. Устаревшие ожидания runtime/UI: подпись зарплаты вместо readonly-поля, удалённые комментарии, три удалённых лимита в golden-ответе, запрет разрешённого изменения истории. Исправлены только ожидания; исходный golden-файл не переписан, сравнение остальных полей и pin сохраняется. Семь ранее упавших случаев закрыты повторным набором: **196 passed, 1 skipped**.
3. Два интеграционных теста тестового schema-4 scorer и tiny offline candidate: первый падает при повторе скоринга, второй — с `Incompatible financial rules`. Это не актуальный принятый пакет, но **проверки остаются открытыми**. Успех реального релизного пакета не объявляется заменой этих тестов.

Полный набор после точечных правок повторно не запускался: повторены связанные проверки выпуска; исследовательские ошибки остаются. Кандидат не следует описывать как «все тесты прошли».
