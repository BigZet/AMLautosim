# Внедрение CatBoost и SHAP

Дата: 14 сентября 2026. Статус: **внедрено и проверено локально**.
Новая изолированная игра: http://localhost:58309/play, организатор:
http://localhost:58309/admin. Удалённое развёртывание не выполнялось.

## Изменения

Риск рассчитывает только aml-catboost-behavior-v2. Модель, extractor и исходные
датасеты не изменялись. Русский словарь всех 84 признаков и нативный Tree SHAP
формируют объяснение каждого результата. Объяснение сохраняется атомарно с оценкой,
не вычисляется заново при просмотре и не доступно до завершения раунда.

Старый скорер не вызывается онлайн. Игровой баланс, проверки операций, пороги
категорий и формула рейтинга сохранены. Метаданные прежних карточек остаются для
чтения фиксированного модельного контракта; старые веса не влияют на прогноз.
Все новые игры — v8. Создание на изменённых финансовых правилах запрещено,
включая переопределения стоимости отдельных операций. В снимке закреплены модель,
её SHA256, extractor, версия объяснения и SHA256 русского словаря.

Runtime использует Python 3.13.15, Linux arm64, CatBoost 1.2.10 CPU. В Docker
включён только итоговый пакет, без обучающих данных и других экспериментов.
Приложение не запускается при ошибке пакета или пробного SHAP. seed не переносит
старые rule-раунды и не удаляет данные. Для этого выпуска создан новый Compose-проект
aml-shap и отдельные volumes; предыдущие пилотные базы не изменялись.

## Команды воспроизведения

```bash
docker build -f deploy/Dockerfile -t aml-shap:integration .
python -m pytest tests/ml tests/api/test_model_integration.py \
  tests/unit/test_expanded_result_ui.py tests/unit/test_nicegui_organizer.py \
  tests/unit/test_profile_history_ui.py tests/unit/test_purchase_ui.py \
  tests/unit/test_timeline_ui.py -q -p no:cacheprovider
python -m scripts.verify_model_integration \
  --dataset resources/aml_dataset/behavior-v3/release \
  --predictions resources/catboost_models/experiment-v2/evaluation/predictions.csv \
  --output /tmp/shap-verification-new.json
ruff check src scripts tests migrations
```

Python-команды выполнялись в образе aml-catboost:v1 с проектом в read-only mount.
Для API-тестов TEST_ADMIN_DATABASE_URL указывает на изолированный PostgreSQL;
фикстура создаёт и удаляет только временную aml_test_* БД. Итоговый runtime собран
отдельно из requirements.txt. Полные логи и сценарии Playwright — в
.local-run/shap-integration/; тестовые секреты не включены в этот отчёт.

## Ограничения и отключение

Это проверка воспроизведения учебной рубрики на синтетических данных, не оценка
банковского AML. SHAP не является фиксированным штрафом, скидкой или гарантией
эффекта изменения операции. Детали SHAP относятся к признакам всей цепочки.
Результаты производительности относятся к указанному локальному окружению.

Проверен целевой набор интеграционных и регрессионных тестов; весь исторический
набор тестов контракта v7 не заявляется прошедшим для нового выпуска.
Предыдущие сохранённые модельные пакеты и их манифесты не переписывались.

При проблемах EXPANDED_ROUNDS_ENABLED=false запрещает создание и новые старты.
Уже сохранённые результаты читаются из БД. Для повтора расчёта требуется исправная
сборка с закреплённой моделью и словарём; fallback на правила отсутствует.
