# Исправления ошибок UI — 20.09.2026

Проверены на том же изолированном стенде http://localhost:18100. Перезапущен только UI. Модель, API и игровые правила не менялись.

- **ERR-UI-01 исправлен.** Подсветка использует отдельный DOM-атрибут, который не стирается обновлением классов Quasar при фокусировке. Повторный переход сбрасывает таймер прежней подсветки. Chrome: для лимита наличных и нехватки баланса выбран правильный input; вычисленный стиль подтверждает анимацию, фон `rgb(255,248,243)` и рамку. Подсветка исчезает по таймеру. [Результат](fixed-highlight.json). Подсветка всей карточки при превышении количества операций также проверена.
- **ERR-UI-02 исправлен.** Номер и идентичность шага берутся из `step_index`/`step_id`, независимо от формулировки сообщения. Chrome: две покупки по 20000 показывают «Шаг 2»; нажатие открывает вторую покупку и подсвечивает сумму.
- **ERR-UI-03 исправлен в UI.** Повторный ₽ нормализуется в видимом тексте и tooltip. Chrome показывает «Общая сумма покупок превышает 30 000 ₽». Нормализация намеренно выполнена на границе отображения: исходные сообщения API и контролируемые исходники пакета модели не изменены. Отдельное мелкое замечание о согласовании «2 карточек» пока остаётся.

Проверки: `python -m pytest tests/unit/test_correction_navigation.py -q` — **3 passed**. Ruff для изменённых Python-файлов — **All checks passed**. Новый тест проверяет переход по структурированному номеру при отсутствии слова «Шаг» в сообщении и отсутствие двойного ₽. Были только прежние предупреждения зависимостей Starlette.
