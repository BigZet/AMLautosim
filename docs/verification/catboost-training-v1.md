# Первая модель CatBoost: обучение и оценка

14 сентября 2026 года, Codex. Рабочая копия на базе `be4cb32`, без коммита.
Модель обучена и оценена офлайн. Публичные API, игровой скоринг и БД не изменены.

## Итог

**По согласованным общим критериям модель готова к отдельному этапу интеграции.**
Это не подтверждение всех поведенческих эффектов игры: ниже явно описаны пробелы.

| Часть | MAE модели | RMSE | P90 абсолютной ошибки | MAE медианы train |
|---|---:|---:|---:|---:|
| Train, 13195 | 0.816 | 1.692 | 1.806 | 8.972 |
| Validation, 2934 | 0.956 | 1.209 | 1.868 | 8.825 |
| Test, 3871 | 2.039 | 2.456 | 4.015 | 8.433 |

На validation 402, на test 533 примера с целевой оценкой ≥75.
В обеих частях **0 занижений более чем на 15** и **0 прогнозов ниже 50**
для этой группы. MAE ≤5 и ниже постоянной медианы train. Все четыре критерия
пройдены одновременно. Ограничение 0–100 не изменило ни одного прогноза.

На test среднее смещение «прогноз минус рубрика» составляет −1.963 балла:
небольшое систематическое занижение сохраняется, хотя заданные пределы соблюдены.
MAE прежнего детерминированного скоринга относительно новой рубрики — 26.533.
Это сравнение двух учебных шкал, а не доказательство превосходства банковской модели.

## Выбор и воспроизводимость

Выбран `candidate-02`: Quantile alpha=0.65, depth=4, l2=3, learning rate=0.05,
136 деревьев из максимальных 2000. Остановка — 100 итераций без улучшения
validation MAE; seed 20260914, четыре CPU-потока. Все 12 конфигураций прошли
validation-критерии, поэтому победителя определила минимальная MAE.

Выбор записан до предсказаний test; train+validation не объединялись.
Дополнительные seed 20260915 и 20260916 дали validation MAE 1.292 и 0.932,
оба прошли критерии. Основная модель не заменялась более удачным дополнительным seed.
Повтор исходного обучения, загрузка сохранённой модели и перестановка признаков
дали максимальное расхождение 0 при допуске 1e-8.

[Модель и все артефакты](../../resources/catboost_models/experiment-v1/README.md).
SHA-256 model.cbm: `3bae009ae3befb2be04deb19e4a0fb2a9fd7677966f0b3cc7eed729e4642014a`.

## Существенные ограничения перед интеграцией

- В validation и test **нет зарплаты**. Она есть только в train: payroll_registry 312,
  service_contract 315, no_reference 237. Общая test MAE не оценивает эти варианты.
- В validation все 2934 цепочки содержат наличные, в test все 3871 — без наличных.
  Такое разделение связано с тремя исходными группами и не менялось при обучении.
- В паре с зарплатой модель меняет риск на −0.94, рубрика — на −11.25 балла.
  В паре со сменой стороны: +20.21 против +32.84. Направления совпадают,
  величины эффекта воспроизводятся заметно слабее. Перед переносом этих эффектов
  в игровую оценку нужен отдельный разбор и, при необходимости, новый эксперимент.
- Семь пар соответствуют направлению с допуском 1 балл; это диагностические
  примеры с известной рубрикой, не независимый тест. «Направление прошло» не означает
  точность величины изменения.
- Всего три группы родителей, фиксированный целевой оборот. Результаты не
  подтверждают эффективность реального AML. Независимую человеческую разметку
  тестовых цепочек этот этап не создаёт.

[Подробный паспорт](../../resources/catboost_models/experiment-v1/evaluation-v2/MODEL_CARD.md)
содержит таблицы покрытия (включая N=0), крупнейшие ошибки с объяснениями,
графики и важность признаков. Самые значимые признаки связаны с историей и
ранее ненаблюдаемыми получателями; важность не трактуется как причинность.

## Окружение и команды

Python 3.13.15, Linux arm64, CatBoost 1.2.10 CPU. Отдельный образ
`aml-catboost:v1`, ID `sha256:f60d72d0e87da810c06b7a5f5f963ee0da2baf5f4be5ef8d2679485f3d14c2dc`.
Полный lock — requirements-ml.txt, исходные требования — requirements-ml.in.
ML-образ не копирует данные внутрь; репозиторий смонтирован readonly, запись
разрешена только в resources/catboost_models. Приложению зависимости не добавлялись.

Команды воспроизведения находятся в [инструкции](../catboost-training.md).
Финальная оценка проверялась через настоящий CLI с запретом всех вызовов fit:

```bash
docker run --rm --name aml-catboost-evaluation \
  -v "$PWD:/workspace:ro" \
  -v "$PWD/resources/catboost_models:/workspace/resources/catboost_models" \
  aml-catboost:v1 python -m tests.ml.verify_evaluation_only \
  --dataset resources/aml_dataset/release-v2-1 \
  --model resources/catboost_models/experiment-v1 \
  --output resources/catboost_models/experiment-v1/evaluation-v2
```

## Промежуточные исправления

Тест метрик обнаружил обработку списка прогнозов как NumPy-массива. Добавлено
явное преобразование на входе; проверка не отключалась.

Первая оценка остановилась при построении графика: атрибут feature_importances_
после загрузки модели оказался None. Оценка использует явный
[get_feature_importance](https://catboost.ai/docs/en/concepts/python-reference_catboostregressor_get_feature_importance)
с PredictionValuesChange, без обучения. Добавлен регрессионный тест.

Затем отчёт дополнен явными пустыми подгруппами N=0 и разницей величин парных
эффектов, чтобы хорошие общие метрики не скрывали отсутствие покрытия зарплаты.
Исходный и промежуточные отчёты сохранены. Во всех трёх predictions.csv SHA-256
одинаковый: `854795c10cc4eade3c7023a598595a09d5c10ec0b23d1b125ac59f8f4748c799`.
Модель, гиперпараметры, рубрика и разделение после открытия test не изменялись.

Снимок кода обучения сохранён отдельно; текущий код отличается оформлением
оценки и сохранением снимка для будущих запусков. Датасет release-v2-1 не изменён.
