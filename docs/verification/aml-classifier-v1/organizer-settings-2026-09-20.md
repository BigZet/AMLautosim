# Настройки организатора — 20.09.2026

Организатор может изменять до старта игры начальные ресурсы, цель, число шагов, ограничения за раунд, минимум/максимум суммы и число использований каждой операции, профиль и наблюдаемую предысторию. Настройки общие для всех участников. API сохраняет запрет изменений после старта, проверку роли организатора и ревизии настроек.

Лимиты покупок используют purchase-policy-v2: настраиваются сумма за раунд и лимиты карточки. Старый purchase-policy-v1 сохраняет прежние значения. Сообщение о превышении показывает установленный лимит.

При отключении истории её покрытие становится unknown; включение возвращает complete и границы текущего периода. Ссылки на стороны, даты, допустимые суммы и согласованность истории продолжает проверять сервер.

## Модель

Пакет: resources/catboost_models/aml-game-organizer-settings-v1. Веса, признаки, калибровка, пороги и обучающие файлы скопированы без изменения. Изменён только контракт допустимых настроек и контрольные суммы исходников. Проверки целостности остаются включёнными; предыдущие выпуски принимаются по точным закреплённым идентификаторам.

Текущий классификатор извлекает признаки из самой цепочки. Предыстория, цель и начальные ресурсы не подаются в модель; они меняют игровой контекст, допустимость цепочки и итоговый игровой балл. Предыстория не становится новым фактором риска от включения редактора. Неизменность прогноза проверена для одинаковых цепочек; произвольные новые игровые конфигурации не являются заново проведённой валидацией качества модели.

## Проверка

- 25 контрольных цепочек: признаки и прогнозы точно совпали с предыдущим пакетом.
- API: сохранение изменённых истории/цели/лимитов, запуск, отправка и скоринг прошли.
- API: участнику запрещено редактировать настройки; организатору запрещено менять их после старта.
- 25 опубликованных сценариев: отправка, скоринг, сохранённые результаты — проверены.
- UI: редактируемые поля и переключение доступности истории проверены NiceGUI user simulation; форма организатора открыта в браузере.
- Настроенная покупка 35 000 проходит при лимите 40 000; две такие покупки нарушают общий лимит 45 000, ошибка показывает именно его.
- Проверки неподдерживаемых изменений и подмены идентификатора модели сохранены.

Локальные API 8003/8005 и UI 8083/8085 переведены на новый пакет. Автоматический перезапуск игр или пересчёт завершённых результатов не выполнялся.
