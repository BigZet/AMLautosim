# Покрытие дополнительных атрибутов операций

Актуальное исправление признаков и разметки с переобучением:
[выпуск контекстной модели 18 сентября](attribute-context-release-2026-09-18.md).

Уточнение после проверки входов модели: полнота покрытия данных не означает
полноту использования атрибутов классификатором. Обнаруженные ограничения и
130 контрольных сравнений описаны в [аудите модели](attribute-model-usage-2026-09-17.md).

Статус: новый набор из 62 000 цепочек полностью пересчитан и проверен;
покрытие полное во всех split. Модель обучена, принята с согласованным исключением
и установлена по умолчанию для новых игр. Существующие раунды сохраняют свои закреплённые модели.

Проверяемый набор: `game-relaxed-v3-60000`, 60 000 цепочек.
Основание проверки — реальные поля v10: `services/projections.py`,
`services/semantic_contract.py`, `domain/operation_purposes.py`, редактор участника,
замороженный каталог сторон и временных интервалов.

| Поле | Что доступно в игре | Что обнаружено в прежнем наборе |
|---|---|---|
| Тип поступления | Банк, платёжный сервис, P2P, вывод с биржи | Только банк |
| Страна банка | RU, KG; только для банковского перевода | Только RU |
| Канал перевода по карте | mobile, web, branch | Только значение по умолчанию mobile |
| Канал снятия | atm, branch | Только значение по умолчанию atm |
| Сторона операции | Допустимый отправитель/получатель из общей истории | Физлица A–D, работодатель, магазин; нет отправителя-биржи |
| Назначение | Допустимые варианты зависят от операции и типа поступления | Неполное покрытие, особенно покупки и наличные |
| Ожидание | 1, 10, 60, 1440 минут; отсутствует у первого шага | Представлено в целом, но не все варианты в каждом split |
| Основание зарплаты | Зарплатный реестр; единственное значение | Представлено |
| Ссылка на основание | Только факты, доступные в текущем общем контексте | Выбор отсутствует: есть лишь факт начального баланса |

Наблюдаемые характеристики контрагентов и предыстории не являются редактируемыми
атрибутами операции. Новые профили или факты не добавляются. Страна банка отсутствует
при P2P, платёжном сервисе и выводе с биржи; у вывода с биржи отправитель — биржа.

Исправление: генератор `scripts/aml_game_curriculum_v9.py` выбирает допустимые значения
до вычисления разметки и финансовой проверки. Суммы, порядок и идентификаторы операций
сохраняются из генератора v8; интервалы частично варьируются независимо. Новый набор
строится заново, метки и ресурсы пересчитываются, связанные наблюдения группируются
до разделения train/validation/calibration/test. Модель обучается заново.

`scripts/audit_aml_attribute_coverage.py` проверяет 82 значения и условных сочетания:
каждое значение по типу операции, тип поступления × допустимая сторона/назначение/страна.
Требуется отсутствие пропусков во всех пяти split. Это покрытие вариантов и указанных
условных сочетаний, а не полный декартов перебор любых комбинаций длинных цепочек.

Доказательство исходных пропусков: [coverage before](attribute-coverage-before.json).
В исходном наборе отсутствовали 33 из 82 проверяемых значений и сочетаний.
Каталог полей получен также через API работающей игры:
[метаданные редактора](attribute-editor-catalog.json).

Первый новый набор из 60 000 цепочек покрыл все варианты в целом, но строгая проверка
обнаружила редкие пропуски ожидания перед зарплатой в отдельных split. Поэтому он
не принят для обучения. Его 60 000 проверенных цепочек дополнены 2000 допустимыми
вариантами с зарплатой не на первом шаге: 850 low, 850 high, 300 grey. Метки и ресурсы
пересчитаны; все дочерние варианты объединены с родителями до разделения выборки.
Основной генератор: `build_aml_attribute_dataset_r1`; дополнение:
`aml_attribute_supplement.py`. Полный декартов перебор по-прежнему не заявляется.

[Итоговое покрытие](attribute-coverage-final.json): пропусков нет ни в одном split;
проверены связи всех 2000 вариантов с родителями. Получены 59 712 групп:
train 37 257, validation 9315, calibration-fit 6177, calibration-check 3085, test 6166.

Новый набор: `E:/AMLautosim-artifacts/aml-probability-v1/game-attributes-v1r1-62000`.
Новая модель: `E:/AMLautosim-artifacts/aml-probability-v1/aml-game-attributes-v1r1-model`.
Выполнены полный replay, проверка покрытия, контроль серой зоны 10–20%, стресс-проверка
с явно согласованным ниже исключением и точная сверка серверного инференса.

## Результат обучения

На 6166 test-цепочках: серая зона 15,4071%, совпадение категорий 99,7892%,
MAE 0,002316. Уверенных ошибок (низкий скор у положительного учебного класса или
высокий у отрицательного) нет. Все offline-критерии пройдены. Калибровка `none`
выбрана сравнением на calibration-check; три окна 2/10/60 минут усредняются.

Выбраны 25 test-примеров (10 low / 10 high / 5 grey), вместе покрывающих все
82 проверяемых значения и условных сочетания, включая интервалы и стороны.
Файл: `tests/fixtures/attribute_classifier_examples.json`.

Метрики относятся к синтетической учебной разметке; доля серой зоны измерена на
заданной учебной смеси. Она не прогнозирует распределение реальных игроков.

## Согласованное отклонение стресс-проверки

На 5000 новых семян получены 1886 допустимых цепочек. Для сценария `2061901495`
прогноз 0,659961 при учебной цели 0,378109; ошибка 0,281852 превышает исходный
допуск 0,25. Обе оценки находятся в серой зоне. Пользователь 17 сентября явно
принял это отклонение сообщением «Это допустимо».

Исходный `gameplay-audit.json` сохранён без изменения: он по-прежнему содержит
`passed=false` и соответствующую причину. В `acceptance.json` отдельно записано
согласованное исключение, привязанное к хешу конкретного отчёта и проверенному
сценарию. Другие ошибки, изменение отчёта или выход оценки из серой зоны не
покрываются этим исключением. Дополнительное обучение более глубокой модели
остановлено; выпускается проверенная модель `aml-game-attributes-v1r1-model`.

Остальные стресс-проверки пройдены: 1863 допустимых копеечных изменения,
789 вариантов ожидания, 80 сохраняющихся высоких структурных паттернов после
ожидания; переименование сторон не меняет результат. MAE 0,005012, максимальный
скачок скора при изменении на копейку — 0.
