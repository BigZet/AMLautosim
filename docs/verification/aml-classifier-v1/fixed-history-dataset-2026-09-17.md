# Подготовка данных после уточнения одной общей истории

Пользователь подтвердил одну неизменную историю для всей игры и запрет
дополнительных профилей. Старая многопрофильная сборка остановлена и сохранена
как исторический эксперимент; обучение по ней не запускалось.

Новый кандидат: [описание и файлы](../../../resources/aml_dataset/aml-fixed-history-v1/candidate-30000/README.md).

- 30 000 допустимых игровых цепочек; классы 0/1 — по 15 000.
- Один `employed-client`, одна предыстория из исходных трёх операций.
- Во всех строках один полный публичный контекст, SHA-256:
  `d7686fb0d55657274793fcdcbf4c72f39f4ff89679b80b0538e15341daa8c8e5`.
- 146 признаков; 1 296 групп при фиксированном общем контексте.
- Контрольные суммы, финансовый движок, JSONL/CSV и отсутствие пересечений
  групп/одинаковых признаков проверены. Три целевых теста прошли.
- Синтетическая разметка не прошла независимую предметную приёмку.
  `release_ready=false`; готовность к финальному обучению не заявляется.

Воспроизведение в новом пустом каталоге:

```powershell
python -m scripts.build_aml_fixed_history_dataset --output <новый-каталог>
python -m scripts.audit_aml_fixed_history_dataset --dataset <новый-каталог>
```

Новый генератор не меняет игровой конфиг, историю между строками или публичные
сведения в зависимости от метки. Допущения о распределении учебных сюжетов
прозрачно записаны в `policy.json`; они не являются эмпирическими вероятностями
фрода. Старые требования к пяти профилям и прежняя приёмка демо отменены;
новые независимая приёмка, протокол обучения и демокейсы остаются отдельной работой.
