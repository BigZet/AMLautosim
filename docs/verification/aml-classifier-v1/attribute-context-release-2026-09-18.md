# Выпуск модели с контекстными атрибутами

Статус: признаки и основания разметки исправлены, модель переобучена,
проверена и установлена по умолчанию для новых игр. Существующие раунды,
цепочки и результаты сохранены без изменений и используют свои закреплённые
пакеты. Общая предыстория не менялась.

## Изменения

Пакет: `resources/catboost_models/aml-game-attribute-context-v1`.
28 численных входов: 14 прежних структурных + 14 контекстных.
Новый извлекатель имеет отдельную версию; код извлечения старых пакетов
не изменён. API принимает обе версии извлекателя в объяснении v5.

Добавлены отношения между способами поступления, странами банка одного
отправителя, каналами, назначениями, адресатами возвратов и фактическими
поступлениями. Назначения учитываются внутри каждого типа операции, включая
поступления и покупки. Единственное основание зарплаты участвует в признаке
зарплатного финансирования покупок. Разметчик отделён от runtime.

Подробные определения и ограничения: [основания разметки](attribute-context-policy-2026-09-17.md).
В частности, конкретная страна или канал не получает самостоятельного штрафа.
Эквивалентные замены могут сохранять оценку; дополнительные атрибуты уточняют
пограничные структурные паттерны.
