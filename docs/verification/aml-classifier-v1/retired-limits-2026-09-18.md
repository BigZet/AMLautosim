# Удаление устаревших игровых лимитов — 18.09.2026

Удалены ограничения количества ночных операций, количества операций с анонимными получателями и их общей суммы. Остальные игровые ограничения, комиссии и расходы ресурсов сохранены. Старые поля конфигурации принимаются, но игнорируются и не переносятся в новые настройки. Изменение применяется к следующей проверке цепочки, без миграции сохранённых результатов.

## Модель и совместимость

Текущий пакет: `resources/catboost_models/aml-game-attribute-context-unlimited-v1`.
Предыдущий пакет и его обучающие/приёмочные артефакты не изменены. В новый пакет скопированы исходные модель, калибровка, словарь и приёмочные файлы без изменения байтов. `release.json` связывает новую совместимость с контрольными суммами исходников и точной идентичностью предыдущего пакета для открытых раундов. Остальные несовместимые конфигурации и неизвестные идентичности по-прежнему отклоняются.

Контрольная выборка до изменения: `tests/fixtures/retired_limits_baseline.json`, 25 цепочек. Все признаки и вероятности совпали точно. Воспроизведение упаковки: `python -m scripts.package_retired_limits <старый-пакет> tests/fixtures/retired_limits_baseline.json <новый-каталог>`.

Архивный `config/model/smoke-scenario.json` сохранён для проверки подписи старой модели v8 при запуске. Адаптер v8 подставляет только три удалённых параметра из этой неизменной проверки в её историческую подпись; движок их не применяет. Это не шаблон нового раунда.
