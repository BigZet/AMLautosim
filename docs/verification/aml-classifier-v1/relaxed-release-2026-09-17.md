- 41 199 связанных групп; разделения train / validation / calibration-fit /
  calibration-check / test: 38 029 / 9094 / 5303 / 2529 / 5045.
- На test: серая зона **15,5203%**, совпадение категорий с учебной разметкой **99,7820%**,
  MAE вероятности **0,002242**. Доля неверных уверенных высоких оценок **0,0519%**,
  неверных уверенных низких — **0%**.
- Три окна 2/10/60 минут усредняются. Для этого выпуска сохранён выбор калибровки
  `none`: sigmoid немного ухудшал Brier и log loss на calibration-check.
- [Серверная проверка](relaxed-runtime-parity.json): все **5045** test-цепочек,
  максимальное расхождение **0**, вызовов разметки на инференсе **0**.
- Дополнительные 5000 новых семян дали 2409 допустимых цепочек: 2378 проверок
  изменения суммы на копейку, 1296 допустимых сценариев ожидания; 233 сохраняют высокий
  скор после ожидания. Переименование сторон не меняет оценку. Максимальное отклонение
  от учебной цели 0,223, MAE 0,00411; все заранее установленные критерии пройдены.
- PostgreSQL/API: 25 новых и 25 исторических примеров прошли сохранение, отправку,
  скоринг, отображение результата, лидерборд, повторный скоринг; проверены конфликты
  редактирования, доступ, несовместимые параметры, отсутствие пакета и откат при ошибке.
  Основной целевой прогон: **21 passed, 1 skipped** (Windows-симлинки), затем **3 passed**
  для обоих закреплённых пакетов. XML: `.local-run/classifier-release/relaxed-tests.xml`.

Высокие метрики измеряют соответствие синтетической учебной разметке. Доли low/high/grey
при генерации заданы 42,5/42,5/15%; 15,52% серой зоны не является прогнозом доли реальных
игроков. Проверка новых семян использует те же семейства маршрутов, не независимую
человеческую AML-экспертизу. Интерес и удобство игры предстоит оценить пользователю.
