## Комплект для запуска

Финальный архив:
[описание и SHA256](release-package.json), локально
`.local-run/audit-fixes/runtime-release.tar.gz`. Внутри `RELEASE-CHECKSUMS.json`.
Образ **aml-shap:audit-fixes-release** собран именно из `release-unpacked`,
полученного из этого архива. Промежуточные runtime-candidate/runtime-final архивы
не являются финальным комплектом. Последняя пересборка изменила только пояснение
в config/README; исполняемые исходники совпадают с проверенной сборкой.

Архив решает воспроизводимость локального комплекта; это не публикация Git-коммита
и не архив обучающих данных. Перед удалённым деплоем нужно сохранить проверенный
архив/образ и отдельно данные обучения. Git-историю и чужие изменения автоматически
не объединяли и не коммитили.

```bash
# В сети собственного изолированного Compose-стенда:
docker run --rm --network aml-fixes_default \
  -v "$PWD:/workspace:ro" \
  -e TEST_ADMIN_DATABASE_URL \
  aml-catboost:v1 python -m pytest tests -q -p no:cacheprovider
# TEST_ADMIN_DATABASE_URL задаётся заранее для db:5432, с тестовыми реквизитами.
python -m scripts.package_runtime --output .local-run/aml-runtime.tar.gz
```

Логи и обёртки `.local-run/audit-fixes/`: `final.log/xml`, `network.log/xml`,
`ui-unit.log/xml`, `package-test.log`, `release-build.log`, `release-start.log`,
`recovery.py/log/json`, `restored_api.py`, `transport.log`, `alembic.log`.
Резервные копии и полные трассы не публикуются: они могут содержать сессии.
