# Проверка очистки перед деплоем — 2026-09-12

Проверена текущая рабочая версия FastAPI + NiceGUI. Предшествовавшие
незакоммиченные изменения игры и UI сохранены; этот отчёт относится к очистке
и подготовке Compose, а не к развёртыванию на целевом сервере.

## Изменения

- Удалены старый Streamlit UI, его общий клиент и cookie-модули, настройки,
  зависимости, Compose-сервисы и инструкции миграции.
- Удалены три неиспользуемые функции представления: `catalog_channels`,
  `context_value_label`, `option_label`. Поиск потребителей включал исходники,
  тесты и скрипты; декораторы маршрутов и страниц сохранены.
- Сохранены CatBoost-адаптер, генератор и датасеты. Адаптер и генератор исключены
  из образа; обучение и интеграция модели не выполнялись.
- Runtime и инструменты тестирования зафиксированы по версиям. Образ загружает
  бинарные колёса, не устанавливает компиляторы и не разрешает дополнительные
  build-зависимости. Прямые требования — `requirements.in`.
- Пароль PostgreSQL передаётся отдельным параметром SQLAlchemy URL, без
  подстановки в строку URL. Явный `DATABASE_URL` сохраняет приоритет для локальных
  инструментов. Alembic и приложение используют единый способ подключения.
- Удалён стандартный bootstrap-пароль. Создание администратора проверяет длину
  10–128 символов; повторный seed сохраняет существующий пароль.
- Обновлены документы по запуску, архитектуре, API, сессиям, скорингу,
  тестированию, обновлению и резервному копированию. Битых локальных ссылок нет.
- `.local-run` исключён из Git и Docker. Копии удалённых файлов и прежних документов
  находятся локально в `.local-run/deploy-check/pre-cleanup`; они не входят в поставку.

## Окружение и результаты

Docker Engine 29.7.2, Compose 5.5.0, Python 3.13.15, Linux aarch64,
PostgreSQL 16. Использованы проекты `aml-deploy-check` и `aml-deploy-restore`
с собственными портами и томами. Рабочие API/UI и БД не перезапускались.

| Ruff, `git diff --check`, валидация JSON | Пройдены |

| Локальные unit-тесты, Python 3.12 | 89 passed |

| Alembic upgrade и `alembic check` | Схема соответствует моделям |

p95 1680 ms, скоринг 35 ms. Это измерение локального Docker-окружения

замена транспорта или обновление всей UI-библиотеки в эту очистку не включены.

## Перезапуск и восстановление

Через реальный HTTP выполнены регистрация, вход обеих ролей, запуск игры,
preview и сохранение девяти операций. Перезапуск API/UI сохранил исходные
API-сессии, ID игры, ревизию и канонические шаги. Затем выполнены отправка,
скоринг и получение результата и рейтинга.

При остановленных API/UI создан `pg_dump -Fc` и архив NiceGUI. Копии восстановлены
в другом Compose-проекте с пустыми томами. Исходные API-сессии действуют,
результат и строки рейтинга совпадают. `generated_at` рейтинга — время запроса,
поэтому не сравнивается. Существовавшие файлы NiceGUI совпадают по SHA-256.
Повторный seed оставляет игру `completed` и сохраняет результаты.

Секреты и сырые логи находятся только в игнорируемом `.local-run/deploy-check`.
Созданные для проверки контейнеры и тома удаляются после проверки.

## Ограничения приёмки

Полное ручное браузерное прохождение не завершено. В Chrome открылась форма
регистрации тестового стека, но после отправки инструмент перестал возвращать
дерево окна и снимок; сброс подключения не помог. Firefox был занят пользователем,
инструмент сообщил о внешнем изменении окна. Пользовательские вкладки не использовались
для дальнейших действий. Регистрация через этот браузер не считается подтверждённой.

Автотесты NiceGUI, реальные HTTP-сценарии и WebSocket не заменяют визуальную
приёмку. Перед выпуском нужно закончить в отдельном браузере: регистрацию,
вход обеих ролей, настройку и старт, редактирование и reload, отправку,
скоринг, рейтинг и сохранение входа после рестарта UI.

Compose-сборка и работа проверены на Linux aarch64. Целевая серверная архитектура,
публичный HTTPS-доступ, реверс-прокси и 50 одновременных браузеров не проверялись.
Существующий черновик nginx не изменён и не подключён.
