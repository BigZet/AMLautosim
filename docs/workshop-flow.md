# Проведение игры

1. Организатор настраивает единственный раунд (`draft`) и запускает его (`active`).
2. Участник собирает одну цепочку. Автосохранение сохраняет последнее подтверждённое
   состояние в БД, чтобы обновление страницы не сбрасывало проделанную работу.
3. Участник отправляет сценарий. Если проверка успешна, редактирование закрывается
   окончательно. Можно только просмотреть отправленную цепочку и ждать результатов.
4. Организатор закрывает приём (`closed`): неотправленные цепочки удаляются.
   Затем идёт скоринг (`scoring`). При ошибке приём остаётся закрытым;
   организатор выясняет причину и повторяет расчёт. Участник без
   отправки получает доступ только к лидерборду; отправивший — ещё и к своей оценке.
5. Новая игра удаляет предыдущие игровые данные, сохраняя аккаунты. Она получает
   новый ID и базовую конфигурацию, которую можно изменить перед запуском.

Паузы, отзыва отправки, истории версий, сохранённых шаблонов и ручных оценок нет.
Интерфейс описан в [nicegui.md](nicegui.md).
