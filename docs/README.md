# Документация AML Workshop Simulator

Этот каталог описывает целевую архитектуру учебного AML-симулятора для мастер-класса
с аудиторией до 500 участников. Документы являются спецификацией для перехода от
автономного Streamlit-прототипа к связке Streamlit, FastAPI и PostgreSQL.

## Статус системы

| Область | Сейчас | Целевая версия v1 |
| --- | --- | --- |
| Participant UI | Streamlit и общий `LocalStore` в памяти процесса | Streamlit вызывает внутренний FastAPI |
| Admin UI | Streamlit вызывает часть существующих API | Streamlit использует версионированный `/api/v1` |
| Бизнес-правила | Разделены между `local_store.py` и FastAPI | Только FastAPI |
| Постоянные данные | Прототип сбрасывает данные после перезапуска | Только PostgreSQL |
| Скоринг | Локальный или упрощенный backend-скоринг | Синхронный пакетный скоринг раунда в FastAPI |
| Развертывание | Запуск отдельных процессов вручную | Одна облачная VM и Docker Compose |

Целевое направление обязательно: автоматического переключения на `LocalStore` при
ошибке API не будет. Пока миграция не завершена, документы явно различают
`реализовано` и `целевая версия`.

эксплуатация → матрица готовности.

## Глоссарий

| Термин | Определение |
| --- | --- |
| Раунд | Одна игровая сессия мероприятия с зафиксированными правилами и карточками. |
| Карточка | Тип финансовой операции и ее ограничения: направление денег, комиссия, энергия и лимиты. |
| Сценарий | Упорядоченная цепочка действий одного участника в одном раунде. |
| Шаг | Один элемент сценария: карточка, сумма, частота, тип получателя и риск страны. |
| Черновик | Сценарий, который участник еще может менять. |
| Отправка | Фиксация текущей версии сценария для последующего пакетного скоринга. |
| Скоринг | Детерминированный расчет риска всех отправленных сценариев раунда. |
| Фактор риска | Объяснимый вклад признака в итоговый риск: сумма, частота, страна, получатель или карточка. |
| Доска | Представление результатов раунда для администратора и разбора со спикером. |

## Архитектурные принципы

- Streamlit отвечает за интерфейс, но не принимает окончательных бизнес-решений.
- FastAPI повторно проверяет любой вход, даже если Streamlit уже выполнил preview.
- PostgreSQL является единственным постоянным источником истины.
- Конфигурация раунда блокируется при активации, чтобы результат можно было повторить.
- Внешний браузер не имеет прямого сетевого доступа к FastAPI и PostgreSQL.
- Учебная модель не позиционируется как реальная банковская AML-система.
- Значения 250 000 ₽, 14 единиц энергии, 8 действий и цель 150 000 ₽ являются
  настройками раунда, а не константами архитектуры.
