# Поддерживаемая модель

Единственный пакет — `resources/catboost_models/aml-game-organizer-settings-v1`.
Реестр `resources/catboost_models/registry.json`, Docker-образ и архив
`scripts.package_runtime` включают только этот пакет. Новые игры используют v10.

Старые модели, экспериментальные пакеты и датасеты удалены. Старые раунды больше
не поддерживаются. Рабочая база данных при очистке репозитория не менялась.
Для перехода используйте новую базу либо штатный перезапуск игры организатором.

Загрузчик проверяет контрольные суммы модели, признаков и исходников. Неизвестная
закреплённая модель вызывает ошибку. Совместимые идентификаторы внутри текущего
пакета остаются частью его контракта целостности и не требуют прежних моделей.

25 сценариев из `tests/fixtures/retired_limits_baseline.json` проверяют текущие
признаки и вероятности. Используемые генераторами шаблоны сценариев находятся
в `config/aml_scenario_templates.json`; это входные данные, а не архив отчётов.
Исследовательские команды остаются инструментами разработки. Повторное обучение
требует нового датасета и проверки качества. Веса текущей модели не изменялись.
