# Конфигурация симулятора

Текущая игра использует контракт v10. Базовый контекст берётся из
`resources/catboost_models/aml-game-organizer-settings-v1/context.json`;
его совместимость проверяется вместе с модельным пакетом. Веса риска
не задаются файлами правил и не редактируются организатором.

Каталог `config/` содержит общие каталоги операций, ресурсные правила,
подписи интерфейса и входные данные офлайн-инструментов. Файлы базового
движка сохранены как зависимости алгоритмов и тестов; они не обозначают
отдельные поддерживаемые выпуски игры.

| Файлы | Назначение |
| --- | --- |
| `operations.json`, `expanded_operations.json` | Определения карточек для каталога |
| `parameters.json`, `channels.json` | Поля и варианты параметров |
| `resource_rules.json` | Ресурсные вычисления |
| `limits.json` | Общие границы входных значений API |
| `editor_labels.json` | Подписи настроек организатора |
| `expanded_behavior.json` | Контекст для общих инструментов расширенного движка |
| `aml_scenario_templates.json` | Необходимые генераторам шаблоны сценариев |
| `base_round.json`, `risk_rules.json`, `synthetic_data.json` | Базовый движок и офлайн-компараторы |

Организатор меняет разрешённые настройки через API или интерфейс в состоянии
`draft`. Старт фиксирует полный снимок карточек, профиля, истории, ресурсов,
цели и ограничений в `rounds.game_config`. Изменение файлов не переписывает
сохранённый снимок; произвольная правка модельного контекста нарушает проверку
целостности пакета.

Одна карточка — одна операция. Поля и допустимые стороны определяются
контрактом конкретного вида операции. Назначение перевода должно соответствовать
способу поступления. Зарплата использует работодателя, обычный входящий перевод
его не принимает. Покупки не входят в целевой оборот.

Модельный риск и ресурсный баланс разделены: [BALANCE.md](BALANCE.md).
Состав и проверки выпуска: [current-release.md](../docs/current-release.md).
