# Automation scripts

Все немногочисленные скрипты сначала хранятся прямо здесь, например `seed.py`,
`smoke.py`, `backup.ps1` и `check_docs.py`. Делить их на `dev/`, `ci/` и `operations/`
имеет смысл только после заметного роста каталога.

Скрипты не должны печатать секреты или персональные данные.
