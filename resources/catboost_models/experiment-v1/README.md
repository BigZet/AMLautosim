# CatBoost: experiment-v1

Обучение завершено. По согласованным общим критериям модель готова к отдельному
этапу интеграции. В игру она не подключена.

- [Модель](model.cbm), [схема 84 признаков](feature-schema.json).
- [Итоговый паспорт, графики и ограничения](evaluation-v2/MODEL_CARD.md).
- [Метрики](evaluation-v2/metrics.json), [разрезы и отсутствие покрытия](evaluation-v2/slices.csv).
- [Выбор модели до test](selection.json), [все 12 экспериментов](experiments.json).
- [Воспроизводимость](reproducibility.json), [дополнительные seed](stability.json).
- [Команды](../../../docs/catboost-training.md), [отчёт проверки](../../../docs/verification/catboost-training-v1.md).

Test MAE 2.039 балла, опасных занижений 0 из 533 высокорисковых цепочек.
Однако зарплаты нет в validation/test, а её диагностический эффект воспроизведён
слабо: −0.94 вместо −11.25 балла рубрики. Менее выражен и эффект смены стороны.
Общие метрики не являются достаточной проверкой этих игровых эффектов.

`evaluation` — первый неполный отчёт, прерванный на графике важности признаков.
`evaluation-final` — исправление графика; `evaluation-v2` — финальное уточнение
покрытия и величины парных эффектов. Прогнозы во всех трёх совпадают побайтно;
модель после открытия test не изменялась. `training-pipeline.py` сохраняет точный
код первоначального обучения, его SHA указан в environment.json.
