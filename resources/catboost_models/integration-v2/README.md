# Модель для отдельного этапа интеграции

Модель прошла новый протокол качества и проверку полного пути inference на всех
test-цепочках. В приложение ещё не подключена.

Использование: `AMLRiskModel(path).predict(steps, config)` из
`src.aml_workshop_simulator.services.aml_risk_model`. Результат — float 0–100.
Модель загружается один раз при создании экземпляра; приложение само её не включает.

Поддерживаются допустимые завершённые сценарии v8 с проверенным финансовым
контрактом. Изменённые ресурсы/лимиты и v7 отклоняются; им нужен прежний скорер
или отдельно проверенная модель. Профиль, история и ID сторон не зашиты в бинарник.

[Паспорт](MODEL_CARD.md), [метрики](metrics.json),
[проверка inference](inference-verification.json), [manifest](manifest.json).

Риск отражает синтетическую учебную рубрику; это не банковская вероятность.
