# Учебный AML-датасет v2-1

Итог этапа 07: 20000 уникальных допустимых сценариев, достигающих цели 400000 ₽.
Рубрика educational-risk-v2-final-1; признаки aml-observable-v2.6; seed 20260914.

| Файл | Назначение |
|---|---|
| scenarios.jsonl | Полные цепочки, снимки раундов, признаки и объяснения |
| features.csv | Входы будущей модели и target_risk_score; служебных полей нет |
| split.csv | Связь строк CSV с ID и train/validation/test |
| feature-schema.json | Версия и список входных признаков |
| configurations.json | Снимки конфигураций по хешу |
| rubric.json | Зафиксированная учебная рубрика |
| quality.json, AUDIT.json | Техническая проверка и распределения |
| CHECKSUMS.json | SHA-256 основных файлов |
| ORIGINAL-HUMAN-FEEDBACK.csv | Исходные 12 человеческих ответов, без подмены |
| FEEDBACK-RESOLUTION.json | Старые/новые расчёты и остаточные расхождения |
| DELEGATED-RESOLUTION.json | Основание финальной технической приёмки |
| diagnostics.jsonl | Недопустимые кандидаты, исключённые из основной выборки |
| unlabeled-challenges.jsonl | 24 архивные цепочки без независимых оценок |

Разбиение: 13195 train, 2934 validation, 3871 test. Родственные шаблоны не разделены.
Первые 2000 записей воспроизведены отдельным запуском пилота. Диапазон риска
32.4844–91.19, медиана 52.3533. Низкие значения и равномерность не навязывались.

Ограничения: три независимые группы родителей, фиксированный оборот, нет независимой
слепой оценки (отменена пользователем). Одна ранее принятая оценка изменилась на +10;
наибольшее оставшееся расхождение с человеческой оценкой — 10.6457. Средняя ошибка
на калибровочных 12 примерах уменьшилась 6.75→2.8203, но это не независимый тест.
Текущая зарплата представлена в 864 цепочках (4.32%); её дорогие ресурсы ограничивают
покрытие после фильтрации. Длинные малые серии проверяются диагностическими тестами.

Тексты объяснений, ID, семейства, baseline и результаты цели не подаются в модель.
Полный отчёт: [этап 07](../../../docs/verification/aml-dataset-stage07-final.md).
CatBoost ещё не обучен и не подключён; общепроектная проверка остаётся этапом 08.
