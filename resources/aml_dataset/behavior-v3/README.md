# Датасет behavior-coverage-v3-1

Отдельное расширение покрытия после анализа первой модели; release-v2-1 не изменялся.
Основные файлы находятся в release/. 26315 уникальных допустимых цепочек, extractor
aml-observable-v3.0, неизменная рубрика educational-risk-v2-final-1.

| Раздел | Строки | Группы | Зарплата | Без наличных |
|---|---:|---:|---:|---:|
| train | 17521 | 96 | 3072 | 1202 |
| validation | 4381 | 24 | 768 | 461 |
| test | 4413 | 24 | 768 | 372 |

Группа — последовательность C/D, где C означает обычное поступление, D — перевод
или снятие. Зарплата, покупки, суммы, стороны, история и интервалы варьируются внутри
группы. Всего 144 группы с 5–10 списаниями; ранее просмотренные структуры не входят
в новые validation/test. Точные дубликаты старого release исключены. В train каждого
основания зарплаты 1024 строки, в validation/test — по 256. В каждой части есть
сочетания зарплаты с наличными и без них. Отбор не выравнивает баллы рубрики.

scenarios.jsonl хранит снимки, последовательности и объяснения; features.csv — 121
отобранный на train признак и целевую оценку; split.csv и groups.json фиксируют
разделение; pairs.json — связанные изменения; CHECKSUMS.json — контрольные суммы.
Полная проверка всех строк: ../../catboost_models/experiment-v2/audit.json.

Seeds и параметры сохранены в protocol.json. Полная повторная генерация пока не
выполнялась. Настроечные неудачные попытки сохранены отдельно в соседних каталогах
release-setup-failed и release-feasibility-failed; это не выборки для обучения.
Четыре списания не позволяют выполнить цель при лимите наличных 120000 и лимите
перевода 80000. Серии одинаковых операций длиннее двух также запрещены движком.
Эти ограничения учитывает генератор; баланс игры не изменялся.

Размер исходных данных около 660 MB. Данные полностью синтетические, доступны
только завершённые допустимые сценарии с оборотом около 400–406 тысяч. Истории
генерируются из ограниченного числа контекстов. Разделение по структурам снижает
утечку между вариациями, но не превращает набор во внешнюю банковскую валидацию.

Инструкция: ../../../docs/catboost-behavior-model.md.
