# Паспорт датасета

Синтетические сценарии учебной игры, не банковские наблюдения. Цель — учебный риск 0–100.
Метки получены отдельной рубрикой; статус проверки указан в manifest.json.
Вход модели: только столбцы manifest.features из features.csv, без scenario_id.
Исходные контексты, объяснения и baseline доступны только для аудита.
Распределения генератора не оценивают распространённость преступлений.
Результаты на этих данных проверяют освоение рубрики, не реальную эффективность AML.
